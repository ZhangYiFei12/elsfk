# 🕹️ TETRIS · 网页版俄罗斯方块（NES 经典版）

仿 **NES 红白机原版** 风格的网页俄罗斯方块：纯黑 CRT 扫描线、像素字体、斜角像素方块、
原版三栏布局（STATISTICS / 游戏区 / TOP·SCORE·NEXT·LEVEL·LINES），
计分与速度曲线完全遵循 NES 原版规则。

**单文件实现**（`index.html`，零依赖、零构建），打开即玩。

## 🎮 在线试玩

👉 **https://zhangyifei12.github.io/rlsfk/**

本地运行：直接用浏览器打开 `index.html` 即可。

## ✨ 特性

- 🎨 NES 原版视觉：黑底 + CRT 扫描线/暗角、Press Start 2P 像素字体、像素斜角方块（白色 L 形闪光）
- 📊 原版三栏布局 + **STATISTICS 掉落统计**（每种方块出现次数实时计数）
- 🏆 **NES 原版计分**：40 / 100 / 300 / 1200 × 当前等级
- ⚡ **NES 原版帧率速度表**（30 级起达到 Kill Screen 极限速度）
- 🧱 SRS 旋转系统 + 墙踢（Wall Kick）、7-Bag 发块、幽灵块、暂存（Hold）
- 🎵 Web Audio 合成音效（可静音）、消行动画、浮动得分、升级提示
- 💾 最高分本地保存（localStorage）、📱 移动端触屏按钮

## ⌨️ 操作

| 按键 | 功能 |
|---|---|
| ← → | 左右移动（长按快速移动） |
| ↓ | 软降，每格 **+1** 分 |
| 空格 | 硬降，每格 **+2** 分 |
| ↑ / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| C / Shift | 暂存（每块限一次） |
| P / Esc | 暂停 / 继续 |
| R | 重新开始 |
| H | 玩法说明 |

## 🏅 计分规则（NES 原版）

| 一次消除 | 得分 |
|---|---|
| 1 行 | **40** × 等级 |
| 2 行 | **100** × 等级 |
| 3 行 | **300** × 等级 |
| 4 行（Tetris） | **1200** × 等级 |

每消除 10 行升 1 级，等级越高下落越快。

## 🛠 技术

纯 HTML + CSS + JavaScript 单文件实现，Canvas 2D 渲染（预渲染方块精灵），
无任何第三方依赖与构建步骤。
